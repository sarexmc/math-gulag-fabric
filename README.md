# MathGulag v2.0.0 (Fabric 1.21.1)
Compilar: instala JDK 21 y Gradle 8.8+, luego `gradle build` (o abre la carpeta en IntelliJ). Jar: build/libs/mathgulag-2.0.0.jar
Requiere Fabric API 0.105.0+1.21.1 en cliente y servidor.
Comandos (op): /mathgulag start | stop | arena | heart | skeleton | version
- arena: construye la cueva de carne alrededor tuyo (necesita chunks cargados, view distance >= 5) y pone el corazon.
- El corazon late solo en el Overworld.

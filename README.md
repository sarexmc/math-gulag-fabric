# MathGulag v2.2.0 (Fabric 1.21.1)
Compilar: JDK 21 + Gradle 8.8+ -> `gradle build` -> build/libs/mathgulag-2.2.0.jar. Requiere Fabric API 0.105.0+1.21.1.
Comandos (op): /mathgulag arena | start | stop | heart | skeleton | version
Juego: arena -> (de pie en un sitio libre, view distance >= 6) construye el corazon. start -> reparte a todos, uno recibe la calavera con pinchos,
resuelve la multiplicacion (25 s) -> venas verdes -> golpea a otro jugador para pasarla (15 s). Fallar o no pasar = explosion. Gana el ultimo.
Con un solo jugador es modo practica.
